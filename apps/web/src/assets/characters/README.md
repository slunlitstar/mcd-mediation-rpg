# 定稿角色素材

五张用户确认的 PNG 原图存放于 `originals/`。原图均为 1536×1024，保留米白背景、全部像素及原始文件内容。
复制时已逐张核对 SHA-256；没有抠图、重绘、调色、压缩或覆盖用户提供的原件。

| 文件 | 角色 | 当前用途 |
| --- | --- | --- |
| `role-saver-original.png` | 省钱薯饼 | 选角、仲裁庭、结果头像 |
| `role-hungry-original.png` | 干饭堡堡 | 选角、仲裁庭、结果头像 |
| `role-fries-original.png` | 脆薯队长 | 选角、仲裁庭、结果头像 |
| `role-cheese-original.png` | 芝士骑士 | 选角、仲裁庭、结果头像 |
| `npc-bag-original.png` | 袋袋调解官 | 首页、共用提示、仲裁庭、空状态和复议 |

`character-assets.ts` 统一管理路径、替代文字、原始尺寸及显示位置。
`CharacterArtwork.tsx` 使用统一正方形显示框，以 CSS 隐藏两侧多余留白；人物与配饰保持完整，原文件不变。
不同图片的身体形状、配饰宽度和高矮本身属于角色设定，不会强行拉伸成相同体型。
网页沿用原图的纸色，并以轻微混合方式协调背景；实际文件保持不透明 PNG。

后续需要透明图或 WebP 等优化版本时，新增 `web/` 或版本化文件，并更新映射，保留 `originals/`。
目前每张原图约 2MB；选角只展示当前浏览的图片，并预载当前角色的选中姿态。共用提示与结果头像使用浏览器原生懒加载，其他角色在展示时加载。
各处复用同一个静态资源 URL，原图已加载时由浏览器缓存复用。图像加载失败会显示简洁占位提示，不回退到旧卡通造型。

## 选中姿态

`selected/role-{saver,hungry,fries,cheese}-selected.png` 为用户确认的四张姿态图，分别基于对应原图编辑，保持原有画风与尺寸。
它们从 `output/imagegen/selected-poses-v1/` 原样复制并逐张核对 SHA-256，不覆盖 `originals/`。
`selectedRoleArtwork` 独立管理选中姿态；仅第三页当前选中角色切换为新图，浏览未选角色、仲裁庭与结果头像继续使用原图。
图片仍在同一正方形框内显示，不改变手机端布局；姿态预载完成前保留原图，原有轻微浮动继续保留。
