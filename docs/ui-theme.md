# 手机优先 UI 配色

本版采用用户确认的「奶油白＋暖麦黄＋深番茄红」，参考柔和纸质底色与红黄食物插画。
`apps/web/src/styles/theme.css` 为统一配色层，在布局样式之后加载。颜色变量在此集中维护。

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#FFF4E3` | 全站背景 |
| `--white` | `#FFFBF3` | 表单、内容与餐品卡 |
| `--yellow` | `#EFB247` | 首页插画区与装饰 |
| `--yellow-soft` | `#F8DFA8` | 人数、成员、预算与食物选项的选中背景 |
| `--yellow-pale` | `#FFF0CD` | 角色展示区与轻量背景 |
| `--red` | `#B62922` | 主按钮、当前步骤、滑条与重要金额 |
| `--red-dark` | `#9E221D` | 主按钮悬停、排除项强调 |
| `--ink` | `#513A2B` | 正文与标题 |
| `--muted` | `#7B624D` | 辅助文字 |
| `--line` | `#DDC6A5` | 卡片分隔与边框 |

手机端保持浅底内容、深色文字和浅底操作栏，页面主操作使用深红。
黄色作为展示与选中区域的背景，文字使用深棕。选中状态仍保留边框、勾选或明确文字。
成功提示保留绿色；自填要求待核对使用暖黄色提示；不喜欢的选项采用浅红底。

第三页维持已确认的角色图和手机控件尺寸，移除了独立的旧色板，统一使用全站配色。
角色原图文件内容不变；未修改数据字段、预算规则或方案生成。

## 验证范围

检查了正文、辅助文字、主按钮、黄色选项、首页黄底文字、成功与待核对提示、小票文字共 9 组关键前景／背景组合。
这些不透明色组合的文字对比度均不低于 4.5:1，最低为 4.74:1。
此检查不代表整站自动可访问性验收；图片叠色、实际设备显示与真机视觉仍需体验确认。
